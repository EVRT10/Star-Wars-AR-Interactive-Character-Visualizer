# Star Wars AR — Interactive Character Visualizer
Menghadirkan pengalaman visualisasi karakter Star Wars secara imersif melalui Augmented Reality. Pengguna cukup mengarahkan kamera ke poster atau gambar karakter Star Wars, dan karakter 3D akan muncul secara real-time lengkap dengan animasi idle/serangan, informasi karakter, dan suara ikonik mereka.
